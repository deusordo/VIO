Check the USB serial connection

Starter lesson · Hardware test pending

Get a repeating message from the board before adding sensors or displays. You’ll need an ESP32-S3-DevKitC-1, a compatible USB data cable, and a computer with Arduino IDE. This lesson uses the board’s USB-to-UART port and no jumper wires.

Set up the board

  1. Install the board support using Espressif’s Arduino setup guide. Match the board and memory settings to your module.
  2. Connect the cable to the USB-to-UART connector shown in the DevKitC-1 guide. Check your board revision for the correct port. In Arduino’s Tools menu, choose the matching serial port and set USB CDC On Boot to Disabled for the UART connector.
  3. Upload the sketch below, then open Serial Monitor at 115200 baud.
void setup() {
  Serial.begin(115200);
}

void loop() {
  Serial.println("VIO: serial link OK");
  delay(1000);
}

Check your result

The expected output is VIO: serial link OK about once a second. Press Reset and check that the output resumes. If the port is missing, try a known data cable. If the monitor is blank, recheck the port, CDC setting, and baud rate. Espressif’s troubleshooting guide covers both USB connectors.

How VIO will document each build

  1. Show what it does. Lead with the purpose and a photo or short demo of the working build.
  2. Make it repeatable. List the exact board revision, parts, pin assignments, software versions, and the steps to build and flash it. Explain the code where it helps a reader change or repair the build.
  3. Show how to test it. Include the expected result, actual bench evidence when available, and common fixes. Label simulations and untested variants explicitly.
